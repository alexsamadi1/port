01 / Production RAG System
Savant — Knowledge Retrieval Infrastructure

Built a production-grade RAG system implementing Anthropic's Contextual Retrieval architecture. Hybrid BM25 + FAISS search with Reciprocal Rank Fusion consistently outperforms single-method retrieval on ambiguous queries. Section-aware chunking for PDF and DOCX, GPT-4o-mini contextualization pipeline, multi-threaded embedding, and S3-backed index with automatic rebuild. Admin analytics dashboard tracks fallback rates, query patterns, and source attribution.
