01 · Federal Procurement Intelligence
ASOS Procurement Framework — Built From Scratch
NOAA / NWS · ASOS Program · 2025–Present

The ASOS program — critical federal weather observation infrastructure supporting NOAA, FAA, and DOD nationwide — needed a more robust, data-driven approach to procurement planning. I built a comprehensive framework from scratch, designing both the data layer and the front-end tools that non-technical logisticians and leadership use to guide purchasing decisions. The result: backorders decreased, zero-balance items were reduced, and more targeted purchasing decisions reduced overall spend while ensuring critical items stayed in stock.

Demand Forecasting
2-year demand formula calculating recommended stock levels using backorders, on-hand, on-order, and annual demand across every line item
SQL Data Layer
5-year historical demand script across 1,000+ parts — the source of truth the entire framework runs on
Criticality Integration
Collaborated with engineering to layer mission-criticality ratings into the model — adding risk context pure demand data couldn't capture
Logistician Lookup Tool
Front-end product: any logistician searches a part number and instantly gets all critical procurement info — designed for non-technical users
Executive Dashboard
Prioritization framework and playbook for leadership: what to buy first, why, and how to think about trade-offs between criticality and cost
Data Cleanup
Identified and resolved data integrity issues — including stale purchase orders that were skewing procurement calculations and causing the program to underestimate true need

02 · Federal Data Recovery
The 1,800-Page Problem
NOAA / NWS · 2025–Present

A legacy financial database was decommissioned. The only surviving copy of multi-million dollar budget and contract data — covering key federal projects and active contracts — was locked inside 1,800+ pages of static PDFs. With no established process for recovering the data, preserving the integrity of those financial records required building a solution from scratch.

I designed an algorithmic extraction engine using Power Query (M) to parse the PDFs and reconstruct the database programmatically, then built a verification layer to audit every record against the source.

99.91% verified accuracy. 150+ labor hours saved. Federal audit risk eliminated. Solo, no playbook.
Solo ownership Power Query (M) Algorithmic extraction Verification layer
03 · Data Infrastructure & Modernization
Modernizing NWS Logistics Reporting Infrastructure
NOAA / NWS · 2025–Present

The NWS Logistics Management Branch had an opportunity to modernize its reporting infrastructure — transitioning from a legacy PDF-based workflow to a more standardized, maintainable system. I led that modernization effort across six stakeholder groups: ASOS, NEXRAD, COOP, Upper Air, the National Reconditioning Center, and LMB leadership.

I transitioned all reports from PDF deliverables to structured Excel reports, then audited and updated the underlying SQL scripts for accuracy and maintainability. To accelerate that process, I built a custom Gemini "Gem" that ingests any SQL script and outputs an executive summary, inline comments explaining each section, and a technical risk assessment — turning hours of manual review into minutes.

To make the new system sustainable long-term, I built a shared cloud repository on Google Drive housing all updated SQL scripts, report templates, and SOPs I authored for report delivery. I also created and shared a Google Calendar with the data team mapping every report to its delivery deadline — centralizing the delivery process in a single shared source of truth.

80% reduction in reporting cycle time. Six stakeholder groups now on standardized Excel reporting. Full cloud repository, SOPs, and shared delivery calendar in place — a centralized, sustainable system built to last.
6 stakeholder groups AI-assisted SQL review Oracle SQL Gemini Google Drive Excel SOPs & documentation
04 · Executive Budget Intelligence
LMB Budget Dashboard — First-Ever Program-Level Visibility
NOAA / NWS · LMB Leadership · 2025

LMB branch leadership wanted greater visibility into how budget was being allocated across programs — specifically the ability to track NEXRAD and ASOS spend separately rather than as a combined figure. I designed a custom SQL query to aggregate all monthly customer requisitions, factor in purchases already made by LMB staff, and feed a front-end dashboard that gives leadership a real-time view of available balance by appropriation code — segmented by program for the first time.

First-ever program-level budget visibility for LMB leadership. NEXRAD vs. ASOS spend now tracked separately — a level of granularity the branch never had before.
